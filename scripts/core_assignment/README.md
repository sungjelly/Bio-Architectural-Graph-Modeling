# Core Assignment Scripts

This directory contains scripts for assigning and plotting CosMx FOVs against tissue-core labels.

- `plot_fov_core_layout.py`: writes FOV/core assignment tables to `results/core_assignment/tables/` and layout figures to `results/core_assignment/figures/`.

Run it from the project root with:

```bash
python scripts/core_assignment/plot_fov_core_layout.py
```
