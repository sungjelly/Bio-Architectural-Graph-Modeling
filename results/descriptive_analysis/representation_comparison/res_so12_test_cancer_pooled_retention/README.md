One shared set of global cluster IDs applies to both cores. Pooled micro F1 uses summed TP, FP and FN pixel counts before calculating the ratio. It is not an average of core F1 values or a combination of independently optimized core selections. Each selected cluster contributes its entire evaluable footprint in both cores; outside pixels remain false positives and omitted inside pixels remain false negatives.

An in-region cell has at least one valid owned pixel inside its core annotation. Pooled retention sums these unweighted cell counts across cores over a fixed denominator. Cluster retention uses the initial global overlapping clusters. Majority-inside sensitivity requires at least half the valid owned cell area inside the annotation.

Every greedy removal maximizes remaining pooled F1 with exact lexicographic ties and continues through the empty union. The path maximum breaks ties by fewest clusters then IDs. Comparison with the exact pooled unrestricted reference does not establish optimality at each cluster count. Full curves, nondominated points and best path F1 subject to ≥90%/≥95% pooled cell retention are retained; the thresholds illustrate the tradeoff.

Cluster groups are selected using both scored annotations. Scores are descriptive agreement, not independent cancer-classifier accuracy. Registration is approximate, annotation exhaustiveness is unverified, and only two cores contribute biological observations. Pooling weights native evaluable pixels equally, not cores or calibrated physical area. Greedy removal does not certify globally optimal subsets at every cluster count.

Exploratory pooled overlap and cell-retention tradeoffs for one shared cluster group across two approximately aligned test cores; no independent accuracy or population superiority.
