An in-region cell has at least one valid owned pixel inside the supplied region. Retention is an unweighted cell count over a fixed denominator. Cluster retention uses the initial positive-overlap clusters as its denominator. Majority-inside retention requires at least half the valid owned cell area inside and is a sensitivity analysis.

Every selected cluster contributes its full evaluable footprint: outside pixels remain false positives and omitted inside pixels remain false negatives. Each removal maximizes the next remaining union F1 with exact lexicographic ties and continues to empty. The best path point breaks ties by fewest clusters then IDs. This greedy path is compared with the exact parent unrestricted maximum; it does not guarantee optimality at each cluster count. Full curves, nondominated points and best F1 subject to ≥90%/≥95% cell retention are included in the report.

All group choices use the scored annotation and are descriptive, not independent cancer-classifier accuracy. Greedy removal chooses the best next deletion, not necessarily the globally best subset at every cluster count. The path maximum is checked against the parent exact unrestricted optimum. Registration is approximate; annotation exhaustiveness and section identity are unverified. Pixels/cells are observations from only two cores, not independent patients.
